# The Orbit

A personal project portfolio and log. Dark-themed, minimal UI for browsing and managing projects across startup ops, hobby builds, and client work.

## Current state

Single self-contained HTML file (`index.html`). No build step, no dependencies — open it in a browser and it works.

## Planned

Migration to Next.js + Vercel with:
- Vercel Blob for persistent storage
- API routes for CRUD operations
- Thumbnail image uploads
- API key auth for AI-agent-driven project management

See `AGENT.md` for full technical context and migration guide.
